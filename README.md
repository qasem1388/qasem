# أرشيف الموظفين

تطبيق ويب (PWA) يُثبَّت على الجوال والكمبيوتر كأي تطبيق، لحفظ ملفات الشركة المهمة في أرشيف مشترك بين الموظفين.

## الميزات

- **حساب لكل موظف**: المدير يضيف الموظفين ويوقف حساباتهم أو يغيّر كلمات مرورهم.
- **ملفات مشتركة** بين جميع الموظفين، مع تصنيفات ووسوم ووصف.
- **البحث بالكتابة** في اسم الملف والتصنيف والوسوم و**داخل محتوى** الملفات (Word و Excel و PDF والنصوص).
  البحث يفهم الاختلافات الشائعة في الكتابة العربية: "احمد" تجد "أحمد"، و"ملف" تجد "الملف"، و"مدرسه" تجد "مدرسة".
- **البحث بالصوت**: اضغط زر الميكروفون وتكلم بالعربية.
- **رفع جميع أنواع الملفات وبأي حجم**: فيديو، صور، صوت، مستندات، تصاميم (PSD و AI و Figma...)، مشاريع مونتاج (Premiere و After Effects و DaVinci...)، ملفات مضغوطة، وغيرها.
  حتى 100 ملف دفعة واحدة، بالاختيار أو بالسحب والإفلات، مع شريط يوضح نسبة التقدم.
- **ملاحظات** تُكتب مباشرة داخل التطبيق، ويمكن تعديلها والبحث في محتواها.
- **روابط ومواقع** تُحفظ مع اسم ووصف، وتُفتح بضغطة.
- **تصفية حسب النوع**: فيديو، صور، تصاميم، مونتاج، مستندات، ملاحظات، روابط...
- **التعديل داخل التطبيق** مع **حفظ النسخة الأصلية دائماً**:
  - ملفات Word (`.docx`): محرر نصوص بالعربية (عريض، عناوين، قوائم، محاذاة).
  - ملفات Excel (`.xlsx`): جدول قابل للتعديل. تتغير الخلايا التي عدّلتها فقط، وتبقى المعادلات والتنسيقات كما هي.
  - الملفات النصية (`.txt` و `.csv` وغيرها).
  - كل حفظ يُنشئ **نسخة جديدة**، ويمكن تنزيل أي نسخة سابقة أو استرجاعها في أي وقت.
- **معاينة وتشغيل** الفيديو والصوت وملفات PDF والصور داخل التطبيق، مع إمكانية التقديم في الفيديو دون تنزيله كاملاً.
- **المشاركة عبر واتساب** بطريقتين:
  - **إرسال الملف نفسه** من الجوال عبر قائمة المشاركة (للملفات حتى 200 ميغابايت).
  - **رابط تنزيل آمن** يُرسل عبر واتساب لأي شخص، حتى من خارج الشركة ودون حساب. تختار مدته (يوم، أسبوع، شهر، أو بدون انتهاء)، وتستطيع إيقافه في أي وقت، وترى عدد مرات التنزيل. الرابط يتوقف تلقائياً إذا حُذف الملف.
- **سجل نشاط**: من رفع أو عدّل أو نزّل أو حذف كل ملف، ومتى.
- **المحذوفات**: الملف المحذوف لا يضيع، والمدير يستطيع استرجاعه.
- **التخزين في Google Drive**: كل نسخة من كل ملف تُحفظ كملف مستقل داخل مجلد "أرشيف الموظفين" في حسابك على Drive، ومعها نسخة احتياطية من قاعدة البيانات.

## التشغيل على جهازك للتجربة

يحتاج [Node.js](https://nodejs.org) الإصدار 22.13 أو أحدث.

```bash
npm install
ADMIN_PASSWORD=كلمة-مرور-قوية npm start
```

افتح `http://localhost:3000` وادخل باسم المستخدم `admin` وكلمة المرور التي وضعتها.
بدون إعداد Google Drive تُحفظ الملفات في مجلد `data/` على الجهاز.

## الرفع على السحابة مع Google Drive

### 1) تجهيز Google Drive (مرة واحدة)

1. ادخل إلى [Google Cloud Console](https://console.cloud.google.com) بحساب Google الذي تريد حفظ الأرشيف فيه، وأنشئ مشروعاً جديداً.
2. من **APIs & Services ← Library** ابحث عن **Google Drive API** واضغط **Enable**.
3. من **Google Auth Platform ← Branding** أدخل اسم التطبيق وبريدك، ثم من **Audience** اختر **External** واضغط **Publish app**.
   > مهم: إذا بقي التطبيق في وضع "Testing" فإن الربط مع Drive ينتهي بعد 7 أيام.
4. من **Clients ← Create client** اختر النوع **Desktop app**، وانسخ **Client ID** و **Client secret**.
5. على جهازك، داخل مجلد المشروع:

   ```bash
   npm install
   GOOGLE_CLIENT_ID=... GOOGLE_CLIENT_SECRET=... npm run drive:auth
   ```

   افتح الرابط الذي يظهر، وسجّل الدخول، ووافق على الصلاحية. إذا ظهرت رسالة "Google hasn't verified this app" اضغط **Advanced** ثم **Continue**.
   سيظهر في الطرفية سطر `GOOGLE_REFRESH_TOKEN=...`. انسخه.

> التطبيق يطلب صلاحية `drive.file` فقط، أي أنه **لا يرى إلا الملفات التي أنشأها بنفسه** ولا يصل إلى باقي ملفاتك في Drive.

### 2) الرفع على Render (له خطة مجانية)

1. أنشئ حساباً على [render.com](https://render.com) واربطه بحساب GitHub.
2. **New ← Web Service** واختر هذا المستودع. سيكتشف Render ملف `Dockerfile` تلقائياً.
3. في **Environment** أضف المتغيرات (انظر `.env.example`):

   | المتغير | القيمة |
   |---|---|
   | `ADMIN_PASSWORD` | كلمة مرور المدير |
   | `JWT_SECRET` | نص عشوائي طويل (40 حرفاً أو أكثر) |
   | `PUBLIC_URL` | رابط التطبيق بعد ربطه بالدومين، مثل `https://archive.example.com` (لروابط المشاركة) |
| `GOOGLE_CLIENT_ID` | من الخطوة 1 |
   | `GOOGLE_CLIENT_SECRET` | من الخطوة 1 |
   | `GOOGLE_REFRESH_TOKEN` | من الخطوة 1 |

4. اضغط **Deploy**. ستحصل على رابط مثل `https://employee-archive.onrender.com`.

على الخطة المجانية يتوقف الخادم بعد 15 دقيقة بدون استخدام، فيستغرق أول فتح بعدها قرابة دقيقة. البيانات لا تضيع لأن قاعدة البيانات تُحفظ في Drive وتُسترجع تلقائياً عند التشغيل. للاستخدام اليومي يُنصح بخطة مدفوعة صغيرة حتى يبقى الخادم يعمل دائماً.

يعمل التطبيق أيضاً على أي استضافة تدعم Docker أو Node.js، مثل Railway و Fly.io و Google Cloud Run.

### 3) تثبيت التطبيق على الأجهزة

- **أندرويد (Chrome)**: افتح الرابط، ثم من القائمة اختر **تثبيت التطبيق** (أو "إضافة إلى الشاشة الرئيسية").
- **آيفون (Safari)**: افتح الرابط، ثم زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **الكمبيوتر (Chrome/Edge)**: أيقونة التثبيت في شريط العنوان، أو من قائمة المستخدم داخل التطبيق ← **تثبيت التطبيق**.

## ملاحظات

- **حجم الملفات**: التطبيق نفسه لا يضع حداً للحجم. يمكن وضع حد اختياري بالمتغير `MAX_UPLOAD_MB`.
  لكن انتبه لحدود الاستضافة:
  - إذا كان أمام الخادم **Nginx** فأضف `client_max_body_size 0;` و `proxy_request_buffering off;` في إعداداته.
  - خدمة **Cloudflare** المجانية لا تقبل أكثر من **100 ميغابايت** للطلب الواحد. لرفع فيديو أكبر، اجعل النطاق يتجاوز Cloudflare (DNS only) أو استخدم نطاقاً فرعياً بدونه.
  - تأكد أن مساحة القرص أو حساب Google Drive (15 غيغابايت مجاناً) تكفي لملفات الفيديو.
- **البحث داخل المحتوى** يشمل Word و Excel و PDF والنصوص والملاحظات حتى 50 ميغابايت. الفيديو والصور والتصاميم يُبحث عنها بالاسم والتصنيف والوسوم والوصف، لذلك يُفضّل كتابة وسوم واضحة لها.

- **البحث الصوتي** يعمل في Chrome و Edge و Safari، ولا يعمل في Firefox. يحتاج إذناً باستخدام الميكروفون واتصالاً بالإنترنت ورابطاً يبدأ بـ `https`.
- **تعديل Word** يحافظ على النص والعناوين والقوائم والجداول والخط العريض والمائل، لكن قد تضيع بعض التنسيقات المعقدة (الرأس والتذييل والألوان والأعمدة). لذلك تبقى النسخة الأصلية محفوظة دائماً، ويمكن أيضاً تنزيل الملف وتعديله في Word ثم رفعه كنسخة جديدة من نافذة "التفاصيل".
- ملفات `.doc` و `.xls` القديمة و PDF والصور تُرفع وتُنزل وتُعرض، لكن لا تُعدَّل داخل التطبيق.
- لا يستطيع موظفان حفظ تعديل على نفس الملف في نفس الوقت: إذا حفظ أحدهما أولاً، يُطلب من الثاني فتح الملف من جديد حتى لا تضيع تعديلات الأول.

## للمطورين

```bash
npm test      # الاختبارات
npm run dev   # تشغيل مع إعادة التحميل التلقائي
```

| المجلد | المحتوى |
|---|---|
| `server/app.js` | واجهة API: الدخول، الملفات، البحث، النسخ، التعديل، الإدارة |
| `server/documents.js` | استخراج النص للبحث، والتحويل من وإلى صيغ Word و Excel |
| `server/arabic.js` | توحيد النص العربي للبحث |
| `server/storage.js` | التخزين في Google Drive أو على القرص |
| `public/` | واجهة التطبيق (HTML/CSS/JS بدون أدوات بناء)، و `sw.js` و `manifest.webmanifest` للـ PWA |
