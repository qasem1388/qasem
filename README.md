# قالب موقع الشركات والمؤسسات التجارية — «شركة الريادة التجارية»

موقع مؤسسي احترافي ثنائي اللغة (العربية RTL افتراضيًا / الإنجليزية LTR) مبني بـ Next.js وTypeScript وTailwind CSS، مصمم ليكون قالبًا قابلًا لإعادة الاستخدام والتخصيص لأي شركة سعودية.

> **حالة المشروع:** المراحل 1–3 مكتملة: الهوية البصرية والصفحة الرئيسية، جميع الصفحات العامة باللغتين، وقاعدة البيانات ولوحة التحكم وتسجيل الدخول. المراحل التالية موضحة في [خارطة الطريق](#خارطة-الطريق).

## التقنيات

| المجال | التقنية |
| --- | --- |
| الإطار | Next.js 16 (App Router) + React 19 + TypeScript |
| التصميم | Tailwind CSS 4 مع متغيرات CSS للهوية التجارية |
| الخط | IBM Plex Sans Arabic عبر `next/font` (يُستضاف محليًا عند البناء) |
| الأيقونات | lucide-react + أيقونات منصات التواصل بصيغة SVG |
| التحقق من النماذج | Zod (في الخادم) |
| قاعدة البيانات | PostgreSQL 14+ مع Prisma 7 (محوّل `pg`) |
| المصادقة | جلسات في قاعدة البيانات + Argon2id لتجزئة كلمات المرور |

## التشغيل محليًا

المتطلبات: Node.js 20.9 أو أحدث، وPostgreSQL 14 أو أحدث.

### 1) إنشاء قاعدة البيانات

```bash
sudo -u postgres psql -c "CREATE ROLE riyada LOGIN PASSWORD 'كلمة-مرور-قوية';"
sudo -u postgres psql -c "CREATE DATABASE riyada OWNER riyada;"
```

> لبيئة التطوير فقط: يحتاج أمر `prisma migrate dev` صلاحية إنشاء قاعدة مؤقتة (shadow database)، فامنح المستخدم `CREATEDB` على جهازك المحلي. في الإنتاج يكفي `migrate deploy` دون هذه الصلاحية.

### 2) الإعداد والتشغيل

```bash
npm install                      # يولّد عميل Prisma تلقائيًا
cp .env.example .env             # ثم عدّل DATABASE_URL
npm run db:migrate               # إنشاء الجداول
npm run db:seed                  # تعبئة المحتوى التجريبي (اختياري)
npm run admin:create -- --email you@company.sa --name "اسمك"
npm run dev                      # http://localhost:3000 — لوحة التحكم: /admin
```

بيئة الإنتاج:

```bash
npm run build                    # يحتاج اتصالًا بقاعدة البيانات لتوليد الصفحات مسبقًا
npm run start                    # المنفذ الافتراضي 3000 (يمكن تغييره بـ PORT=8080)
```

### إنشاء حساب المدير الأول بأمان

لا يحتوي المشروع على أي حساب أو كلمة مرور افتراضية. يُنشأ المدير الأول من سطر الأوامر على الخادم نفسه:

```bash
npm run admin:create -- --email you@company.sa --name "اسمك"
```

- تُطلب كلمة المرور مرتين دون إظهارها على الشاشة (أو عبر المتغير `ADMIN_PASSWORD` في الإعداد الآلي).
- شروط كلمة المرور: 12 حرفًا على الأقل، حروف وأرقام، ليست شائعة ولا تحتوي البريد الإلكتروني.
- لاستعادة الوصول عند نسيان كلمة المرور: `npm run admin:create -- --email you@company.sa --reset` (يعيد التعيين وينهي كل الجلسات).
- بعد الدخول، أنشئ حسابات بقية الفريق من **لوحة التحكم ← المستخدمون والصلاحيات**.

أوامر مفيدة:

| الأمر | الوظيفة |
| --- | --- |
| `npm run lint` / `npm run typecheck` | فحص الكود والأنواع |
| `npm run format` | تنسيق الكود بـ Prettier |
| `npm run db:migrate` | تطبيق ترحيلات قاعدة البيانات (إنتاج) |
| `npm run db:migrate:dev` | إنشاء ترحيل جديد بعد تعديل `prisma/schema.prisma` (تطوير) |
| `npm run db:seed` | إعادة تعبئة المحتوى التجريبي (لا يمس المستخدمين أو الرسائل) |
| `npm run db:studio` | متصفح مرئي لقاعدة البيانات |
| `npm run admin:create` | إنشاء مدير رئيسي أو إعادة تعيين كلمة مروره |
| `npm run generate:art` | إعادة توليد الصور التوضيحية في `public/demo` |

## هيكل المشروع

```
src/
├─ app/[locale]/          # كل صفحات الموقع العام تحت /ar و /en
│  ├─ layout.tsx          # التخطيط الجذري: الاتجاه، الخط، ألوان الهوية، الهيدر والفوتر
│  ├─ page.tsx            # الصفحة الرئيسية (ترتيب الأقسام من المحتوى)
│  ├─ actions.ts          # Server Actions لنموذجي التواصل وطلب عرض السعر
│  ├─ not-found.tsx       # صفحة 404 مخصصة ومترجمة
│  └─ [...rest]/          # أي مسار غير معروف → 404 المترجمة
├─ app/admin/             # لوحة التحكم (تخطيط جذري مستقل عربي RTL)
│  ├─ login/              # صفحة تسجيل الدخول
│  ├─ (panel)/            # الصفحات المحمية: الرئيسية، المستخدمون، السجل، حسابي
│  └─ actions/            # Server Actions مع تحقق الصلاحيات في الخادم
├─ server/                # كود الخادم فقط: الجلسات، كلمات المرور، الصلاحيات، سجل العمليات
├─ generated/prisma/      # عميل Prisma المولّد (غير مرفوع إلى Git)
├─ proxy.ts               # توجيه اللغة + منع الوصول المبدئي لـ /admin بدون جلسة
├─ components/
│  ├─ layout/             # الشريط العلوي، الهيدر، القائمة الجوالية، الفوتر، زر واتساب
│  ├─ home/               # أقسام الصفحة الرئيسية + registry.tsx لربط الأقسام
│  ├─ forms/              # الحقول ونموذجا التواصل وعرض السعر
│  └─ ui/                 # أزرار، عناوين أقسام، أيقونات، حركة الظهور
├─ content/demo/          # مصدر البيانات التجريبية التي يزرعها prisma/seed.ts
├─ lib/
│  ├─ content.ts          # طبقة الوصول للمحتوى (تقرأ من قاعدة البيانات)
│  ├─ db.ts               # عميل Prisma المشترك
│  ├─ theme.ts            # تحويل ألوان الهوية إلى متغيرات CSS مع التحقق منها
│  ├─ validation.ts       # مخططات Zod للنماذج
│  └─ rate-limit.ts       # تحديد معدل الإرسال
├─ i18n/                  # إعدادات اللغات ونصوص الواجهة (ar / en)
└─ types/content.ts       # أنواع المحتوى المشتركة
```

### مبادئ التصميم المعماري

- **كل المحتوى في قاعدة البيانات:** الإعدادات (الهوية، التواصل، القوائم، التذييل، الرئيسية، من نحن) مخزنة كمستندات في جدول `Setting`، وبقية المحتوى في جداول مستقلة. الواجهات تقرأ عبر `src/lib/content.ts` فقط.
- **النصوص ثنائية اللغة** مخزنة كـ JSON بالشكل `{ "ar": "…", "en": "…" }`، ما يسهّل إضافة لغة ثالثة مستقبلًا.
- **ترتيب أقسام الرئيسية وإظهارها/إخفاؤها** من `homePage.sections` في `src/content/demo/home.ts`.
- **الهوية البصرية ديناميكية:** الألوان ونصف قطر الزوايا تُحقن كمتغيرات CSS (`--brand-primary` …) وتُشتق منها الدرجات تلقائيًا، فتغيير لون واحد ينعكس على الموقع كاملًا.
- **النصوص ثنائية اللغة** من نوع `Localized = { ar, en }`.

## ما تم إنجازه في المرحلة الأولى

- شريط علوي (هاتف، بريد، ساعات العمل، منصات التواصل، تبديل اللغة).
- هيدر ثابت مع قائمة منسدلة للقوائم الفرعية، وقائمة جوالية جانبية (فتح/إغلاق، Esc، حبس التركيز، قفل التمرير).
- الصفحة الرئيسية بـ 13 قسمًا: البانر الرئيسي وأزرار الدعوة، نبذة، الرؤية والرسالة والقيم، الخدمات، الإحصائيات بعدّاد متحرك، المشاريع مع تصفية (الكل/مكتمل/قيد التنفيذ)، القطاعات، لماذا تختارنا، شعارات الشركاء، آراء العملاء، أحدث الأخبار، طلب عرض سعر، تواصل معنا.
- تذييل شامل (روابط، بيانات التواصل، السجل التجاري والرقم الضريبي، منصات التواصل).
- زر واتساب عائم وزر العودة للأعلى.
- نموذجا التواصل وطلب عرض السعر يعملان مع تحقق في الخادم، حقل مصيدة للرسائل المزعجة (honeypot)، تحديد معدل الإرسال (5 محاولات / 10 دقائق لكل IP)، حفظ مدخلات المستخدم عند الخطأ، ورقم مرجعي لطلب عرض السعر.
- صفحة 404 مخصصة باللغتين.
- SEO أساسي: عنوان ووصف، canonical، hreflang، Open Graph، وبيانات Schema.org من نوع Organization.
- رؤوس أمان HTTP أساسية، وإخفاء ترويسة `X-Powered-By`.
- دعم `prefers-reduced-motion`، رابط «تخطَّ إلى المحتوى»، تباين ألوان مطابق لـ WCAG 2.2 AA (تم الفحص بـ axe-core دون مخالفات).
- بدون تمرير أفقي من 360px حتى الشاشات الكبيرة.

## ما تم إنجازه في المرحلة الثانية

جميع الصفحات العامة مرتبطة فعليًا ومولَّدة مسبقًا (SSG) باللغتين — 108 صفحة دون أي رابط معطّل:

| القسم | المسارات |
| --- | --- |
| من نحن | `/about` (النبذة، الرؤية والرسالة، القيم، الأهداف، المسيرة، كلمة الإدارة، الفريق، الهيكل التنظيمي، الشهادات) — `/about/team` — `/about/certifications` |
| الخدمات | `/services` (مجمّعة حسب التصنيف) — `/services/[slug]` (التفاصيل، المميزات، معرض الصور، طلب عرض سعر/واتساب/اتصال) |
| المشاريع | `/projects` (تصفية حسب الحالة والقطاع) — `/projects/[slug]` (العميل، الموقع، السنة، نطاق العمل، الصور، مشاريع مشابهة) |
| القطاعات | `/sectors` — `/sectors/[slug]` (مع مشاريع القطاع) |
| المركز الإعلامي | `/media` — `/media/news` — `/media/articles` — `/media/announcements` — `/media/events` — `/media/photos` (معرض مع عارض صور) — `/media/videos` — `/media/news/[slug]` (مع المشاركة الاجتماعية) |
| العملاء | `/clients` (الشعارات، قصص النجاح، آراء العملاء) |
| التوظيف | `/careers` — `/careers/[slug]` (نموذج تقديم مع رفع السيرة الذاتية) |
| النماذج | `/quote` (مع مرفق اختياري واختيار الخدمة تلقائيًا من صفحة الخدمة) — `/contact` (الفروع، الخريطة، النموذج، المنصات) |
| صفحات إضافية | `/faq` — `/privacy` — `/terms` — `/cookies` — `/sitemap` — صفحة 404 مخصصة |

- مسار تنقل (Breadcrumbs) لكل صفحة مع بيانات `BreadcrumbList`.
- عنوان ووصف وcanonical وhreflang لكل صفحة، وبيانات منظمة حسب النوع: `Service`، `Article/NewsArticle`، `Event`، `JobPosting`، `FAQPage`، `LocalBusiness`.
- **رفع الملفات بأمان:** يُتحقق من الحجم والامتداد **ومن توقيع الملف الفعلي** (لا يُقبل ملف تنفيذي غُيّر امتداده إلى pdf). السيرة الذاتية: PDF/DOC/DOCX حتى 5MB، مرفق عرض السعر: PDF/صور/Office حتى 8MB.
- الخريطة من OpenStreetMap (بدون مفتاح API أو ملفات تتبع)، ومقاطع الفيديو لا تُحمّل من YouTube إلا عند الضغط على التشغيل.
- تذييل محدّث بروابط القطاعات والعملاء وخريطة الموقع والصفحات القانونية.

## ما تم إنجازه في المرحلة الثالثة

### قاعدة البيانات

- مخطط كامل في `prisma/schema.prisma` يغطي: الإعدادات، الصفحات، الخدمات وتصنيفاتها، المشاريع، القطاعات، الأخبار، العملاء، الآراء، قصص النجاح، الصور والفيديو، الفروع، الأسئلة الشائعة، الوظائف، إضافة إلى جداول الرسائل وطلبات عروض الأسعار وطلبات التوظيف والملفات (تُفعّل في المرحلة السادسة).
- ترحيلات في `prisma/migrations`، وسكربت زراعة يعيد تعبئة المحتوى التجريبي دون المساس بالمستخدمين أو الطلبات.
- الموقع العام يقرأ الآن من قاعدة البيانات بالكامل.

### لوحة التحكم `/admin`

| الصفحة | الوصف |
| --- | --- |
| تسجيل الدخول | `/admin/login` |
| الرئيسية | إحصائيات المحتوى والطلبات الواردة وآخر العمليات |
| المستخدمون والصلاحيات | إنشاء وتعديل وإيقاف وحذف المستخدمين، إعادة تعيين كلمات المرور |
| سجل العمليات | كل العمليات المهمة مع التصفية والترقيم |
| حسابي | تغيير كلمة المرور وعرض الجلسات النشطة وإنهاء الجلسات الأخرى |

**الأدوار:**

| الدور | الصلاحيات |
| --- | --- |
| مدير رئيسي | كل شيء: المحتوى، الإعدادات، المستخدمون، سجل العمليات |
| محرر محتوى | إدارة المحتوى والرسائل والطلبات |
| قراءة ومتابعة | عرض المحتوى والرسائل والطلبات فقط |

### الأمان

- **كلمات المرور:** Argon2id بمعاملات OWASP (19MiB، تكراران)، مع سياسة قوة وتوقيت ثابت حتى للبريد غير الموجود.
- **الجلسات:** رمز عشوائي 256-بت في كوكي `HttpOnly` و`SameSite=Lax` و`Secure` (في الإنتاج) ومقيّد بالمسار `/admin`؛ يُخزّن في قاعدة البيانات **تجزئة SHA-256** للرمز فقط. صلاحية 12 ساعة مع تمديد تلقائي عند الاستخدام.
- **الصلاحيات تُتحقق في الخادم** في كل صفحة وكل Server Action (`requireUser`)، وليس في الواجهة فقط. تم اختبار استدعاء الإجراءات مباشرة دون المرور بالواجهة.
- **CSRF:** Server Actions ترفض الطلبات القادمة من أصل (Origin) مختلف، إضافة إلى `SameSite=Lax`.
- **تحديد محاولات الدخول:** 5 محاولات فاشلة لكل بريد أو 20 لكل IP خلال 15 دقيقة، مخزنة في قاعدة البيانات (تصمد بعد إعادة التشغيل).
- **حماية من الإغلاق الذاتي:** لا يمكن للمدير تغيير دوره أو إيقاف/حذف حسابه، ولا يمكن إزالة آخر مدير رئيسي نشط.
- إيقاف حساب أو إعادة تعيين كلمة مروره ينهي جلساته فورًا؛ تغيير كلمة المرور ينهي جلسات الأجهزة الأخرى.
- صفحات اللوحة مرسلة بـ `noindex` و`Cache-Control: no-store`.
- لا تُرفع أي أسرار إلى Git (`.env` مستبعد، ولا توجد كلمات مرور افتراضية).

## ملاحظات مهمة حول البيانات التجريبية

- جميع الأرقام (السجل التجاري، الرقم الضريبي، الهاتف، واتساب، البريد) **وهمية** ويظهر تنويه «موقع تجريبي» أسفل الصفحة طالما `demoMode: true` في `src/content/demo/site.ts`.
- شعارات الشركاء وآراء العملاء وقصص النجاح **توضيحية** ولا تمثل جهات حقيقية، وأسماء العملاء في المشاريع محجوبة.
- أسماء فريق العمل والشهادات والجهات المانحة **أمثلة توضيحية**، ونصوص الخصوصية والشروط تحتاج مراجعة قانونية قبل النشر.
- مقاطع الفيديو التجريبية بلا معرّف YouTube، فتفتح قناة الشركة؛ أضف `youtubeId` لتفعيل التشغيل داخل الموقع.
- الصور في `public/demo` **رسومات أصلية مولّدة برمجيًا** عبر `scripts/generate-demo-art.mjs` (لا تخضع لأي ترخيص خارجي). يُنصح باستبدالها بصور فوتوغرافية حقيقية أو مرخصة قبل الإطلاق — عدّل مسار الصورة في ملفات المحتوى، وإن كانت الصور على نطاق خارجي فأضفه إلى `images.remotePatterns` في `next.config.ts`.

## خارطة الطريق

1. ✅ هيكل المشروع والهوية البصرية والصفحة الرئيسية المتجاوبة.

7. تحسين SEO (sitemap، robots) والأمان والأداء.
8. الاختبارات وتجهيز النشر وتوثيق الاستضافة والنسخ الاحتياطي.
