# قالب موقع الشركات والمؤسسات التجارية — «شركة الريادة التجارية»

موقع مؤسسي احترافي ثنائي اللغة (العربية RTL افتراضيًا / الإنجليزية LTR) مبني بـ Next.js وTypeScript وTailwind CSS، مصمم ليكون قالبًا قابلًا لإعادة الاستخدام والتخصيص لأي شركة سعودية.

> **حالة المشروع:** المرحلة الأولى مكتملة (هيكل المشروع + الهوية البصرية + الصفحة الرئيسية المتجاوبة). المراحل التالية موضحة في [خارطة الطريق](#خارطة-الطريق).

## التقنيات

| المجال | التقنية |
| --- | --- |
| الإطار | Next.js 16 (App Router) + React 19 + TypeScript |
| التصميم | Tailwind CSS 4 مع متغيرات CSS للهوية التجارية |
| الخط | IBM Plex Sans Arabic عبر `next/font` (يُستضاف محليًا عند البناء) |
| الأيقونات | lucide-react + أيقونات منصات التواصل بصيغة SVG |
| التحقق من النماذج | Zod (في الخادم) |
| قاعدة البيانات (المرحلة 3) | PostgreSQL + Prisma |

## التشغيل محليًا

المتطلبات: Node.js 20.9 أو أحدث.

```bash
npm install
cp .env.example .env.local
npm run dev          # بيئة التطوير على http://localhost:3000
```

بيئة الإنتاج:

```bash
npm run build
npm run start        # المنفذ الافتراضي 3000 (يمكن تغييره بـ PORT=8080)
```

أوامر مفيدة:

| الأمر | الوظيفة |
| --- | --- |
| `npm run lint` | فحص الكود بـ ESLint |
| `npm run typecheck` | فحص الأنواع بـ TypeScript |
| `npm run format` | تنسيق الكود بـ Prettier |
| `npm run generate:art` | إعادة توليد الصور التوضيحية في `public/demo` |

## هيكل المشروع

```
src/
├─ app/[locale]/          # كل صفحات الموقع العام تحت /ar و /en
│  ├─ layout.tsx          # التخطيط الجذري: الاتجاه، الخط، ألوان الهوية، الهيدر والفوتر
│  ├─ page.tsx            # الصفحة الرئيسية (ترتيب الأقسام من المحتوى)
│  ├─ actions.ts          # Server Actions لنموذجي التواصل وطلب عرض السعر
│  ├─ not-found.tsx       # صفحة 404 مخصصة ومترجمة
│  └─ [...rest]/          # أي مسار غير معروف → 404 المترجمة
├─ proxy.ts               # توجيه / إلى اللغة المحفوظة أو العربية افتراضيًا
├─ components/
│  ├─ layout/             # الشريط العلوي، الهيدر، القائمة الجوالية، الفوتر، زر واتساب
│  ├─ home/               # أقسام الصفحة الرئيسية + registry.tsx لربط الأقسام
│  ├─ forms/              # الحقول ونموذجا التواصل وعرض السعر
│  └─ ui/                 # أزرار، عناوين أقسام، أيقونات، حركة الظهور
├─ content/demo/          # البيانات التجريبية (الإعدادات، الرئيسية، الخدمات، المشاريع…)
├─ lib/
│  ├─ content.ts          # طبقة الوصول للمحتوى (ستُربط بقاعدة البيانات في المرحلة 3)
│  ├─ theme.ts            # تحويل ألوان الهوية إلى متغيرات CSS مع التحقق منها
│  ├─ validation.ts       # مخططات Zod للنماذج
│  └─ rate-limit.ts       # تحديد معدل الإرسال
├─ i18n/                  # إعدادات اللغات ونصوص الواجهة (ar / en)
└─ types/content.ts       # أنواع المحتوى المشتركة
```

### مبادئ التصميم المعماري

- **كل المحتوى قابل للتعديل من البيانات وليس من الكود:** اسم الشركة، الشعار، الألوان، القوائم، نصوص الأقسام، الإحصائيات، الخدمات والمشاريع كلها في `src/content/demo` ويتم قراءتها عبر `src/lib/content.ts` فقط. عند ربط قاعدة البيانات ولوحة التحكم ستتغير هذه الطبقة وحدها دون المساس بالواجهات.
- **ترتيب أقسام الرئيسية وإظهارها/إخفاؤها** من `homePage.sections` في `src/content/demo/home.ts`.
- **الهوية البصرية ديناميكية:** الألوان ونصف قطر الزوايا تُحقن كمتغيرات CSS (`--brand-primary` …) وتُشتق منها الدرجات تلقائيًا، فتغيير لون واحد ينعكس على الموقع كاملًا.
- **النصوص ثنائية اللغة** من نوع `Localized = { ar, en }`.

## ما تم إنجازه في المرحلة الأولى

- شريط علوي (هاتف، بريد، ساعات العمل، منصات التواصل، تبديل اللغة).
- هيدر ثابت مع قائمة منسدلة للقوائم الفرعية، وقائمة جوالية جانبية (فتح/إغلاق، Esc، حبس التركيز، قفل التمرير).
- الصفحة الرئيسية بـ 13 قسمًا: البانر الرئيسي وأزرار الدعوة، نبذة، الرؤية والرسالة والقيم، الخدمات، الإحصائيات بعدّاد متحرك، المشاريع مع تصفية (الكل/مكتمل/قيد التنفيذ)، القطاعات، لماذا تختارنا، شعارات الشركاء، آراء العملاء، أحدث الأخبار، طلب عرض سعر، تواصل معنا.
- تذييل شامل (روابط، بيانات التواصل، السجل التجاري والرقم الضريبي، منصات التواصل).
- زر واتساب عائم وزر العودة للأعلى.
- نموذجا التواصل وطلب عرض السعر يعملان مع تحقق في الخادم، حقل مصيدة للرسائل المزعجة (honeypot)، تحديد معدل الإرسال (5 محاولات / 10 دقائق لكل IP)، حفظ مدخلات المستخدم عند الخطأ، ورقم مرجعي لطلب عرض السعر.
- صفحة 404 مخصصة باللغتين.
- SEO أساسي: عنوان ووصف، canonical، hreflang، Open Graph، وبيانات Schema.org من نوع Organization.
- رؤوس أمان HTTP أساسية، وإخفاء ترويسة `X-Powered-By`.
- دعم `prefers-reduced-motion`، رابط «تخطَّ إلى المحتوى»، تباين ألوان مطابق لـ WCAG 2.2 AA (تم الفحص بـ axe-core دون مخالفات).
- بدون تمرير أفقي من 360px حتى الشاشات الكبيرة.

## ملاحظات مهمة حول البيانات التجريبية

- جميع الأرقام (السجل التجاري، الرقم الضريبي، الهاتف، واتساب، البريد) **وهمية** ويظهر تنويه «موقع تجريبي» أسفل الصفحة طالما `demoMode: true` في `src/content/demo/site.ts`.
- شعارات الشركاء وآراء العملاء **توضيحية** ولا تمثل جهات حقيقية.
- الصور في `public/demo` **رسومات أصلية مولّدة برمجيًا** عبر `scripts/generate-demo-art.mjs` (لا تخضع لأي ترخيص خارجي). يُنصح باستبدالها بصور فوتوغرافية حقيقية أو مرخصة قبل الإطلاق — عدّل مسار الصورة في ملفات المحتوى، وإن كانت الصور على نطاق خارجي فأضفه إلى `images.remotePatterns` في `next.config.ts`.

| --- | --- |
| اسم الشركة، الوصف، الشعار، الألوان، بيانات التواصل، القوائم، التذييل | `src/content/demo/site.ts` |
| نصوص أقسام الرئيسية وترتيبها وإظهارها | `src/content/demo/home.ts` |
