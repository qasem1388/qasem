# متجر قاسم — متجر إلكتروني احترافي

متجر إلكتروني عربي كامل بواجهة RTL وتصميم قريب من قوالب Shopify، فيه مزايا متاجر سلة، ومربوط بالبوابات والخدمات السعودية.

## المزايا

### الدفع
| الطريقة | الربط |
|---|---|
| **ميسر Moyasar**: مدى، فيزا، ماستركارد، Apple Pay، STC Pay | فاتورة دفع مستضافة، ثم تحقق من الخادم (مع مطابقة المبلغ) + Webhook |
| **تمارا Tamara**: تقسيط على 4 دفعات | جلسة Checkout ثم Authorise، والتحصيل (Capture) تلقائياً عند الشحن، وإشعارات موقّعة JWT |
| **تابي Tabby**: 4 دفعات بدون فوائد | جلسة Checkout ثم التحقق من حالة الدفعة، والتحصيل تلقائياً عند الشحن |
| **الدفع عند الاستلام** | برسوم تحددها من الإعدادات |

### الشحن
- **سمسا SMSA** و**أرامكس Aramex**: إصدار البوليصة وطباعتها، ورقم التتبع، ومبلغ التحصيل عند الاستلام (COD)، ووزن الشحنة.
- التوصيل **من 2 إلى 5 أيام عمل لجميع مدن المملكة**، مع حساب التاريخ المتوقع (الجمعة والسبت عطلة) وعرضه في صفحة المنتج والدفع والطلب.
- شحن مجاني فوق مبلغ تحدده، مع شريط تقدّم يظهر في السلة.

### الذكاء الاصطناعي
- **توليد 6 صور احترافية من صورة واحدة**:
  - الوضع الافتراضي (مجاني): 6 تصاميم استوديو، وهي خلفية بيضاء، وتدرّج، ومنصة عرض، وخلفية دافئة، وفخامة داكنة، ولقطة مقرّبة.
  - وضع `IMAGE_PROVIDER=openai`: يحلّل Claude صورة المنتج ويكتب 6 مشاهد تصوير مخصّصة، ثم يولّدها نموذج صور مع الحفاظ على شكل المنتج.
- **8 عناوين مختلفة جذرياً لكل منتج**: سيو، تسويقي، عاطفي، مختصر، فاخر، إعلان (30 حرفاً أو أقل)، سوشيال، وسؤال. ومعها وصف مختصر ووصف تفصيلي وعنوان ووصف سيو وكلمات مفتاحية ورابط عربي.
- **الوكيل الذكي للوحة التحكم** (`/admin/agent`): تكتب له طلبك بالعربي فينفّذه عبر 27 أداة تغطي المتجر كله:
  - المنتجات والألوان
  - تعديل الأسعار بشكل جماعي
  - الطلبات وحالاتها
  - إصدار بوالص الشحن
  - العملاء
  - الكوبونات
  - التصنيفات
  - السلايدرات والبنرات
  - التقييمات
  - الإعدادات
  - التقارير والتوصيات التسويقية

### المتجر
- سلايدر رئيسي، ودوائر التصنيفات، وبنرات التصنيفات، وبنر عروض، وعروض محدودة بعداد تنازلي.
- أقسام: منتجات مميزة، والأكثر مبيعاً، ووصل حديثاً، وآراء العملاء، وشارات الدفع.
- **ألوان المنتج**: لكل لون صورة ومخزون وسعر مستقل، ومقاسات اختيارية.
- معرض صور، وتقسيط تمارا/تابي محسوباً تحت السعر، وتنبيه "بقي X قطع".
- زر "اشترِ الآن"، وشريط شراء ثابت في الجوال، وسؤال عن المنتج عبر واتساب.
- السلة الجانبية، والمفضلة، والمنتجات التي شاهدها العميل مؤخراً، والمنتجات المشابهة، والبحث والفرز.
- صفحة الدفع: كوبونات الخصم، وحساب الضريبة 15%، والتحقق من رقم الجوال السعودي ومن المخزون.
- تتبع الطلب برقم الطلب والجوال، وتقييمات العملاء (تظهر بعد موافقة الإدارة).
- **واتساب**: زر عائم، وفي صفحة المنتج، وفي صفحة الطلب، ومراسلة العميل من لوحة التحكم.
- **أدوات تسويقية**:
  - إشعارات "اشترى أحد العملاء مؤخراً"، وهي مبنية على طلبات حقيقية.
  - النشرة البريدية.
  - Google Analytics.
  - Meta Pixel وSnap Pixel وTikTok Pixel.

### السيو
- عنوان ووصف لكل صفحة، وروابط Canonical، وOpen Graph، وTwitter Cards.
- بيانات منظمة JSON-LD تشمل:
  - Product: مع العروض لكل لون، والتقييمات، ومدة الشحن 2-5 أيام، وسياسة الاسترجاع.
  - BreadcrumbList.
  - Organization.
  - WebSite مع SearchAction.
- `sitemap.xml` يتضمن صور المنتجات، و`robots.txt`، وروابط عربية، ومعاينة Google داخل محرر المنتج.

### لوحة التحكم
تشمل لوحة التحكم:
- إحصائيات ومخطط للمبيعات.
- الطلبات: تغيير الحالة، وإصدار البوليصة، وسجل الطلب.
- محرر المنتجات، ومعه استوديو الذكاء الاصطناعي.
- التصنيفات، والسلايدرات والبنرات، والكوبونات، والعملاء، والتقييمات.
- الإعدادات، وتعرض حالة الربط مع كل خدمة.

## التشغيل

```bash
npm install
cp .env.example .env      # ثم عدّل القيم
npm run setup             # ينشئ قاعدة البيانات ويضيف بيانات تجريبية
npm run dev               # http://localhost:3000
```

لوحة التحكم على `/admin`. بيانات الدخول هي `ADMIN_EMAIL` و`ADMIN_PASSWORD` من ملف `.env`.

إذا لم تُضبط مفاتيح البوابات و`PAYMENT_TEST_MODE="true"`، تظهر صفحة دفع تجريبية لمحاكاة الدفع الناجح أو الفاشل. وإذا لم تُضبط مفاتيح شركات الشحن، تُنشأ أرقام تتبع تجريبية تبدأ بـ `TEST-`.

### للإنتاج
1. غيّر `provider` في `prisma/schema.prisma` إلى `postgresql` وحدّث `DATABASE_URL`.
2. اضبط في `.env`:
   - `SITE_URL` إلى نطاقك.
   - `AUTH_SECRET` إلى قيمة عشوائية طويلة.
   - `PAYMENT_TEST_MODE="false"`.
3. أضف مفاتيح ميسر وتمارا وتابي وسمسا وأرامكس و`ANTHROPIC_API_KEY`.
4. سجّل روابط الإشعارات في لوحات البوابات:
   - ميسر: `/api/payments/moyasar/webhook`
   - تمارا: `/api/payments/tamara/webhook`
   - تابي: `/api/payments/tabby/webhook`
5. تُحفظ الصور المرفوعة في `UPLOAD_DIR`، فاجعله مجلداً دائماً على الخادم.
6. شغّل `npm run build && npm start`.
