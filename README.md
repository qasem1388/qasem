# حاسبة قوس قزح 🌈

آلة حاسبة بسيطة بألوان زاهية، وكل زر له صوت:

- **الأرقام**: كل رقم يعزف نغمة موسيقية مختلفة.
- **العمليات** (+ − × ÷ %): صوت انزلاق قصير.
- **النتيجة (=)**: لحن صغير من أربع نغمات.
- **المسح والحذف والخطأ**: أصوات خاصة بها.

زر 🔊 أعلى الحاسبة يشغّل الصوت أو يوقفه. تعمل أيضاً من لوحة المفاتيح (الأرقام، + - * /، Enter، Backspace، Esc).

## التشغيل

افتح الملف `index.html` في أي متصفح. لا يحتاج إلى تثبيت أي شيء؛ الأصوات تُولَّد مباشرة عبر Web Audio API.
