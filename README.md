# نظام موقع ولوحة تحكم الجمعيات الأهلية (NGO Website + CMS)

نظام ويب ديناميكي متكامل للجمعيات الأهلية في المملكة العربية السعودية، يتكون من:

- **موقع إلكتروني عام** عربي (RTL)، متجاوب بالكامل (جوال / تابلت / كمبيوتر) ومهيأ لمحركات البحث.
- **لوحة تحكم إدارية** عربية مستقلة على `/admin` لإدارة **كل** محتوى الموقع دون تعديل الكود.
- **واجهة API** آمنة، و**قاعدة بيانات حقيقية** (PostgreSQL أو SQLite)، و**نظام ملفات** للصور وملفات PDF.

> لا يوجد أي محتوى ثابت داخل الكود: النصوص والصور والملفات والأخبار والإحصائيات والصفحات والقوائم والألوان والشعار كلها تُدار من لوحة التحكم.

## التشغيل السريع

المتطلبات: **Node.js 22** أو أحدث.

```bash
npm install
cp .env.example .env          # ثم عدّل القيم (خاصة ADMIN_PASSWORD و SESSION_SECRET)
npm start
```

افتح: `http://localhost:3000` للموقع، و `http://localhost:3000/admin` للوحة التحكم.

عند **أول تشغيل** يقوم النظام تلقائيًا بـ:
1. إنشاء جميع جداول قاعدة البيانات (Migrations).
2. إنشاء الصلاحيات والأدوار الأساسية (مدير عام، محرر محتوى، الموارد البشرية والتطوع).
3. إنشاء حساب المدير الأول من `ADMIN_EMAIL` و `ADMIN_PASSWORD`
   (إذا لم تُحدَّد كلمة مرور يتم توليد كلمة مرور عشوائية وطباعتها في سجل التشغيل مرة واحدة).
4. تعبئة **بيانات تجريبية** (شرائح، أخبار، مشاريع، ملفات حوكمة، أعضاء، هيكل تنظيمي، وظائف...) لتشاهد الموقع مباشرة.
   لتعطيلها: `SEED_DEMO=false`.

> بدون `DATABASE_URL` يستخدم النظام SQLite في `data/database.sqlite` — مناسب للتجربة والتطوير.

## التشغيل على Replit

1. أنشئ Repl جديدًا من هذا المستودع (Import from GitHub). ملف `.replit` مُجهّز مسبقًا (Node.js 22 + PostgreSQL).
2. من تبويب **Database** أنشئ قاعدة PostgreSQL — يضيف Replit المتغير `DATABASE_URL` تلقائيًا.
3. من تبويب **Secrets** أضف:
   - `SESSION_SECRET`: نص عشوائي طويل (48 حرفًا أو أكثر).
   - `ADMIN_EMAIL` و `ADMIN_PASSWORD`: بيانات المدير الأول.
   - `SITE_URL`: رابط الموقع النهائي (مثل `https://example.org`).
   - `NODE_ENV=production` عند النشر.
4. اضغط **Run**. سيتم إنشاء الجداول والبيانات التجريبية تلقائيًا.

> **ملاحظة مهمة حول الملفات المرفوعة:** تُحفظ الصور وملفات PDF حاليًا على قرص الخادم (`uploads/` و `storage/private/`).
> عند النشر احرص على أن يكون القرص دائمًا (Reserved VM) واعمل نسخًا احتياطية دورية (`npm run backup`).
> خدمة التخزين مفصولة في `src/core/storage.js` بحيث يمكن لاحقًا استبدالها بتخزين سحابي (Replit Object Storage أو S3) دون تعديل بقية النظام.

## ربط قاعدة البيانات

| البيئة | الإعداد |
|---|---|
| تطوير محلي سريع | اترك `DATABASE_URL` فارغًا ← SQLite |
| PostgreSQL محلي | `DATABASE_URL=postgres://user:pass@localhost:5432/ngo` |
| PostgreSQL سحابي (Neon / Supabase / Replit) | `DATABASE_URL=postgres://...` و `DATABASE_SSL=true` إذا طُلب SSL |

الترحيلات (Migrations) تعمل تلقائيًا عند التشغيل، ويمكن تشغيلها يدويًا: `npm run db:migrate`.
جميع الاستعلامات تتم عبر Knex باستعلامات مُعاملة (Parameterized) لمنع SQL Injection، والمخطط متوافق مع SQLite و PostgreSQL ومختبر على كليهما.

## الأقسام والمزايا

### الموقع العام
- **الهوية البصرية ديناميكية**: الشعار، الاسم، العبارة، الألوان (رئيسي، ثانوي، النصوص، الخلفية، الأزرار، الفوتر)، الخط، وحجم الخط — تُطبّق فورًا عبر متغيرات CSS.
- **الصفحة الرئيسية**: هيدر بالشعار والقائمة وزرّي "تواصل معنا" و"تطوع معنا"، سلايدر متجاوب (1920×250) مع تشغيل تلقائي وسحب باللمس، نبذة مختصرة، الرسالة والرؤية والقيم، إحصائيات بعدّاد متحرك، خدماتنا ومشاريعنا (3 في الصف)، آخر الأخبار، فوتر كامل.
- إظهار/إخفاء كل قسم من الصفحة الرئيسية من لوحة التحكم.
- قائمة منسدلة على الكمبيوتر وقائمة جانبية (Hamburger) على الجوال، وجداول قابلة للتمرير على الجوال.
- عارض PDF داخل الصفحة، معرض صور (Lightbox)، فيديوهات YouTube تُحمّل عند الضغط فقط (أداء أفضل).
- تصميم مناسب لكبار السن: خط واضح وحجم قابل للتعديل، أزرار كبيرة، تباين جيد، دعم لوحة المفاتيح وقارئات الشاشة.

### لوحة التحكم (عربية بالكامل RTL)
- لوحة معلومات بالإحصائيات (الأخبار، المشاريع، المتطوعون، الوظائف، الطلبات، الأعضاء، ملفات الحوكمة، الصفحات...) وآخر الطلبات والعمليات.
- **CRUD كامل لكل الأقسام** مع: بحث، فلترة، ترتيب بالأعمدة، **سحب وإفلات لترتيب الظهور**، تفعيل/تعطيل بنقرة، تأكيد قبل الحذف.
- **حالة النشر** (مسودة / منشور / غير منشور) للأخبار والصفحات والمشاريع والوظائف، مع زر **معاينة** يعرض المحتوى كما سيظهر للزائر قبل نشره.
- **محرر نصوص احترافي (TinyMCE)** بالعربية: عناوين، ألوان، محاذاة، قوائم، جداول، روابط، صور، فيديو، ملفات PDF، فواصل، اقتباسات.
- **مكتبة ملفات**: رفع متعدد بالسحب والإفلات، معاينة، نسخ الرابط، نص بديل، حذف، واستخدام الملفات داخل أي محتوى.
- **منشئ القوائم**: سحب وإفلات متداخل لإنشاء قوائم منسدلة، ربط بصفحة ديناميكية أو رابط مخصص، فتح في نافذة جديدة.
- **الصفحات الديناميكية**: عدد غير محدود من الصفحات على `/page/slug` مع إظهار في القائمة/الفوتر وإعدادات SEO لكل صفحة.
- **المتطوعون وطلبات التوظيف ورسائل التواصل**: بحث وفلترة، تغيير الحالة مباشرة من الجدول، ملاحظات إدارية، تصدير Excel (CSV).
- **المستخدمون والأدوار والصلاحيات**: عدد غير محدود من المدراء، أدوار مخصصة بصلاحيات (عرض/إدارة) لكل وحدة.
- **سجل العمليات (Audit Log)**: الدخول، المحاولات الفاشلة، الإضافة، التعديل، الحذف، الرفع، تغيير الإعدادات، تنزيل الملفات الخاصة.

### SEO
عنوان ووصف وصورة مشاركة لكل صفحة/خبر/مشروع/وظيفة، Slug قابل للتعديل (يدعم العربية)، Open Graph و Twitter Cards، Canonical URLs،
`sitemap.xml` و `robots.txt` ديناميكيان، بيانات منظمة (Structured Data): `NGO`، `NewsArticle`، `JobPosting`، `BreadcrumbList`،
ورمز تحقق Google Search Console من الإعدادات.

│   │   └── admin-menu.js      # القائمة الجانبية للوحة التحكم

│   ├── routes/
│   │   ├── admin/             # واجهات API للوحة التحكم (CRUD عام + إعدادات + ملفات + قوائم)
│   │   └── public/            # صفحات الموقع العام + النماذج + SEO
│   ├── views/                 # قوالب EJS للموقع العام (partials + pages)

├── public/                    # CSS و JS الموقع العام
├── admin/                     # تطبيق لوحة التحكم (HTML + CSS + JS Modules)

## الأمان

- كلمات المرور مشفرة بـ **bcrypt** (12 جولة) ولا تُحفظ أو تُرسل كنص صريح.
- **جلسات آمنة** مخزنة في قاعدة البيانات، كوكيز `HttpOnly` و `SameSite` و `Secure` في الإنتاج، وتجديد معرف الجلسة عند الدخول.
- **حماية من التخمين**: تحديد عدد محاولات الدخول، وقفل الحساب مؤقتًا بعد 5 محاولات خاطئة.
- **CSRF** لكل عملية تعديل في لوحة التحكم والنماذج العامة، و**Honeypot** وحد للطلبات في النماذج العامة.
- **SQL Injection**: جميع الاستعلامات عبر Knex باستعلامات معاملة.
- **XSS**: هروب تلقائي لكل النصوص في القوالب، وتنقية محتوى المحرر بقائمة سماح (يُسمح بإطارات YouTube وخرائط Google فقط)، وسياسة **CSP** صارمة عبر Helmet.
- **الملفات**: قائمة سماح للامتدادات (JPG, JPEG, PNG, WEBP, PDF)، فحص **التوقيع الحقيقي** للملف (Magic Bytes)، حدود للحجم، أسماء عشوائية، ومنع SVG.
- **الملفات الحساسة** (السير الذاتية) خارج المجلد العام، ولا تُنزّل إلا لمستخدم مسجل يملك الصلاحية، مع تسجيل كل تنزيل.
- **البيانات الحساسة**: رقم هوية المدير التنفيذي لا يظهر إلا إذا فعّل المدير خيار إظهاره.
- **الصلاحيات** تُفحص في الخادم لكل طلب API (وليس في الواجهة فقط)، وتعطيل المستخدم ينهي جلساته فورًا.
- الأسرار عبر متغيرات البيئة فقط؛ لا توجد كلمات مرور أو مفاتيح داخل الكود.

## إضافة قسم جديد للنظام

النظام مبني على **تعريف موحد للأقسام** — لا حاجة لكتابة واجهات أو نماذج جديدة:

1. أنشئ ترحيلًا جديدًا في `src/db/migrations/` لإضافة الجدول.
2. أضف تعريف المورد في `src/core/resources.js` (الحقول وأنواعها، أعمدة القائمة، الفلاتر، البحث، الترتيب، الصلاحية).
3. أضف رابطه في `src/core/admin-menu.js`.

ستظهر تلقائيًا في لوحة التحكم صفحة القائمة (بحث/فلترة/ترتيب/سحب وإفلات/تفعيل/حذف) ونموذج الإضافة والتعديل والتحقق من المدخلات وسجل العمليات.
ثم أنشئ قالب العرض في `src/views/pages/` ومساره في `src/routes/public/index.js`.

## النسخ الاحتياطي

`npm run backup` ينشئ مجلدًا في `backups/<التاريخ>` يحتوي على:
- قاعدة البيانات (نسخة SQLite متسقة، أو تصدير JSON لجداول PostgreSQL — ويُنصح بـ `pg_dump` في الإنتاج).
- الملفات العامة والملفات الخاصة.

يمكن جدولة الأمر عبر Cron أو Replit Scheduled Deployments. البنية جاهزة لإضافة الرفع التلقائي للنسخ إلى تخزين خارجي.

## إضافة اللغة الإنجليزية مستقبلًا

- نصوص الواجهة العامة في `src/i18n/ar.js` و `src/i18n/en.js` وتُستدعى عبر `t('key')` في القوالب، واتجاه الصفحة (`dir`) واللغة (`lang`) يُحددان من إعداد اللغة.
- التنسيقات تعتمد على الخصائص المنطقية في CSS (`inline-start/end`) فتعمل تلقائيًا مع LTR.
- الخطوة التالية المقترحة: إضافة جدول `translations` (أو أعمدة `*_en`) للمحتوى، وبادئة `/en` في الروابط، ووسوم `hreflang`.
