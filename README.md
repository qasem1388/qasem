# حديقة البومة 🦉

لعبة تعليمية تفاعلية بالصوت للأطفال بعمر ٦ سنوات.

افتح `index.html` في المتصفح والعب:

- **عُدّ معي**: المس الأشياء لتعدّها، ثم اختر الرقم الصحيح (١–٩).
- **الألوان**: أين اللون الأحمر؟
- **الحيوانات**: أسماء الحيوانات وأصواتها.
- **الحروف**: أ مثل أرنب، ب مثل بطة.

البومة تتكلم بالعربية عبر صوت الجهاز، مع أصوات مرحة للإجابة الصحيحة والخاطئة، ونجوم واحتفال في النهاية.
