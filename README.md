# قاسم للتطوير الرقمي

موقع صفحة واحدة لعرض المواقع والتطبيقات التي يصممها قاسم محمد الشريف، مع لوحة تحكم لإضافة الأعمال.

- `index.html`: الموقع
- `admin/`: لوحة التحكم (PHP، بدون قاعدة بيانات)
- `data/projects.json`: الأعمال المحفوظة
- `uploads/`: صور المشاريع
- `logo.svg`: الشعار
