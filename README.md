# إعلان ساعة Louis Martin — موشن جرافيك 30 ثانية

إعلان عمودي 1080×1920 بأسلوب Luxury Cinematic لسناب شات وإنستغرام (Reels/Stories)، مبني بالكامل بالكود (Python + FFmpeg) ويمكن تعديله وإعادة تصديره بأمر واحد.

## الملفات الجاهزة

| الملف | الوصف |
|---|---|
| `output/louis_martin_ad_no_vo.mp4` | النسخة النهائية **بدون تعليق صوتي**: موسيقى + مؤثرات. H.264 High و AAC 48kHz و 30fps و30 ثانية بالضبط، وارتفاع الصوت ‎-14 LUFS |
| `output/louis_martin_ad_final.mp4` | النسخة **مع التعليق الصوتي**: يجري إنشاؤها تلقائيًا عند وضع تسجيلات الصوت في `assets/vo/` (انظر أدناه) |
| `docs/voiceover_script.md` | نص التعليق مع التوقيتات، جاهز للمعلّق الصوتي |

## إعادة التصدير

```bash
pip install numpy scipy pillow     # يلزم أيضًا ffmpeg، وPillow مع libraqm لتشكيل الحروف العربية
python3 build.py                   # يرسم الصورة والصوت ويصدّر كل النسخ (حوالي 5 دقائق)
python3 build.py --audio-only      # بعد إضافة التعليق الصوتي: إعادة مزج الصوت فقط (أسرع)
python3 src/render.py --preview 1,12.5,27 --guides   # لقطات PNG مع حدود المساحة الآمنة
```

## التعديل السهل (`config.json`)

- **صورة الساعة**: `product_image`. يلزم أن تكون صورة على خلفية بيضاء، والقص وتحديد مركز الساعة يجريان تلقائيًا.
- **اسم المتجر**: `store_name`، و**زر الطلب**: `cta`.
- **اسم العلامة**: `brand_latin` / `brand_arabic`.
- **كل نصوص الشاشة**: داخل `texts`. يتقلص حجم الخط تلقائيًا إذا طال النص، فلا يخرج عن الحدود الآمنة.
- **الألوان**: داخل `colors`.
- **التعليق الصوتي**: داخل `voiceover` (ملف كل جملة ووقت بدايتها).
- **المشهد الرابع**: `scene4_background` يقبل فيديو أو صورة حقيقية (معصم رجل سعودي مثلًا)، فتُعرض النصوص فوقه بدل الخلفية المجردة.
- **التوقيتات**: كلها في `src/timeline.py`، والصورة والمؤثرات الصوتية تقرأ من المصدر نفسه فتبقى متزامنة.

## إضافة التعليق الصوتي

1. سجّل الجمل الخمس من `docs/voiceover_script.md` بصوت معلّق سعودي.
2. ضعها باسم `assets/vo/line1.wav` … `line5.wav` (أي صيغة يقرأها ffmpeg تصلح)، أو ضع ملفًا واحدًا كاملًا مدته 30 ثانية باسم `assets/vo/full.wav`.
3. شغّل `python3 build.py --audio-only`. تنخفض الموسيقى تلقائيًا (Ducking بمقدار 10–12 ديسيبل تقريبًا) أثناء الكلام، ويُنبَّهك السكربت إذا تجاوزت جملة الوقت المخصص لها.

## المكونات

```
config.json        النصوص والألوان والصورة والمتجر
build.py           البناء الكامل والمزج والتصدير
src/timeline.py    توقيت المشاهد والمؤثرات (مصدر واحد)
src/render.py      رسم المشاهد الخمسة (عمق ثلاثي الأبعاد بالمنظور، انعكاسات ضوئية، قطرات، درع 3D، زر CTA)
src/audio.py       موسيقى ومؤثرات مولّدة بالكود (بلا حقوق طرف ثالث)
src/cutout.py      قص الساعة من الخلفية البيضاء وتحديد مركزها
assets/            الصورة والخطوط (Cairo وTajawal وCinzel، رخصة OFL)
```

## ملاحظات

- **الموسيقى والمؤثرات** مولّدة بالكامل بالكود داخل المشروع، فلا تحتاج ترخيصًا تجاريًا من طرف ثالث.
- **المساحة الآمنة**: كل النصوص بين y=270 وy=1250 مع هامش جانبي 80 بكسل، وهذا يناسب واجهات سناب وReels وStories معًا.
