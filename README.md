# حساباتي | Hesabati

برنامج محاسبي سعودي لسطح المكتب (Windows) للمحلات والمؤسسات والشركات الصغيرة والمتوسطة.
مبني بـ **Tauri 2 + React + TypeScript + Rust** مع قاعدة بيانات محلية **مشفّرة (SQLCipher / AES-256)**، ويعمل بالكامل دون إنترنت.

> **حالة المشروع:** المرحلة الأولى (الأساس البرمجي) مكتملة. الوحدات المحاسبية التشغيلية تُنفَّذ في المراحل القادمة.
> البرنامج **لا يدّعي** التوافق مع متطلبات هيئة الزكاة والضريبة والجمارك (ZATCA) قبل اجتياز اختبارات المطابقة الرسمية.

## ما الذي يتضمنه الإصدار الحالي (المرحلة الأولى)

- تطبيق سطح مكتب حقيقي (نافذة Tauri) بواجهة عربية كاملة واتجاه RTL، مع بنية جاهزة للإنجليزية.
- قاعدة بيانات SQLite مشفّرة بالكامل (SQLCipher 4) بمفتاح عشوائي 256 بت يُحفظ في **مدير بيانات اعتماد Windows** — لا مفاتيح ولا كلمات مرور داخل الكود.
- مهاجرات (migrations) مرقّمة ومحمية ببصمة SHA-256.
- معالج إعداد أول تشغيل: بيانات المنشأة + إنشاء المدير الأول (مرة واحدة فقط، ضمن معاملة واحدة).
- تسجيل دخول آمن: Argon2id، قفل الحساب بعد 5 محاولات فاشلة لمدة 15 دقيقة، جلسات في الذاكرة تنتهي بعد 30 دقيقة خمول.
- صلاحيات منفصلة للمدير والمحاسب والكاشير، يُتحقق منها في الخادم (Rust) لكل أمر.
- سجل تدقيق غير قابل للتعديل أو الحذف (Triggers) ومحمي بسلسلة تجزئة SHA-256 لكشف أي تلاعب.
- الواجهة الرئيسية: قائمة جانبية بالأقسام الـ 18، شريط علوي باسم المنشأة والمستخدم، لوحة تحكم (ببيانات **توضيحية** معلنة بوضوح)، الوضع الفاتح والداكن.
- شاشة بيانات المنشأة (تُحفظ وتبقى بعد إعادة التشغيل)، وشاشة المستخدمين وسجل التدقيق.
- محرك القيد المزدوج في الطبقة الخلفية (بدون واجهة بعد): منع القيد غير المتوازن، الترحيل الذري، منع تعديل/حذف القيود المرحّلة، القيود العكسية، منع تكرار الترحيل، الفترات المالية المقفلة — مع حماية مزدوجة في التطبيق وقاعدة البيانات.
- 87 اختبارًا آليًا (54 في Rust و33 في الواجهة). انظر [تقرير الاختبارات](docs/TEST_REPORT.md).

## المتطلبات للتطوير

| الأداة | الإصدار |
|---|---|
| Node.js | 22 أو أحدث |
| Rust | 1.80 أو أحدث (stable) |
| Windows | Microsoft C++ Build Tools + WebView2 (موجود في Windows 10/11) |
| Windows (لبناء OpenSSL المضمّن مع SQLCipher) | [Strawberry Perl](https://strawberryperl.com) و [NASM](https://nasm.us) في PATH |
| Linux (للتطوير فقط) | `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev` |

## التشغيل

```bash
npm install          # مرة واحدة
npm run app:dev      # يفتح البرنامج كتطبيق سطح مكتب مع إعادة التحميل التلقائي
```

## الاختبارات

```bash
npm run test:all     # فحص الأنواع + اختبارات الواجهة + اختبارات Rust
```

## بناء ملفات التثبيت لـ Windows (EXE و MSI)

**الطريقة الأسهل — GitHub Actions:** كل `push` يشغّل سير العمل `.github/workflows/ci.yml` الذي يبني على جهاز Windows
ملفَّي التثبيت ويرفعهما باسم `hesabati-windows-installers` في صفحة التشغيل (Actions → آخر تشغيل → Artifacts).

**على جهاز Windows محلي:**

```powershell
npm install
npm run app:build -- --bundles nsis,msi
```

الملفات الناتجة:
- `src-tauri\target\release\bundle\nsis\Hesabati_0.1.0_x64-setup.exe`
- `src-tauri\target\release\bundle\msi\Hesabati_0.1.0_x64_ar-SA.msi`

> ملفات التثبيت غير موقّعة رقميًا حاليًا؛ قد يظهر تحذير Windows SmartScreen. التوقيع يحتاج شهادة توقيع كود (انظر [الأمان](docs/SECURITY.md)).

## أين تُحفظ البيانات؟

- قاعدة البيانات: `%APPDATA%\sa.hesabati.desktop\hesabati.db` (مشفّرة).
- مفتاح التشفير: مدير بيانات اعتماد Windows ← `Hesabati / database-encryption-key`.
- **مهم:** المفتاح مرتبط بحساب مستخدم Windows. نقل قاعدة البيانات إلى جهاز آخر يتطلب ميزة النسخ الاحتياطي المشفّر (المرحلة الثانية).
