# قاسم للتطوير الرقمي

موقع صفحة واحدة لعرض المواقع والتطبيقات التي يصممها قاسم محمد الشريف، مع لوحة تحكم لإضافة الأعمال.

- `index.php`: الموقع
- `admin/`: لوحة التحكم (PHP، بدون قاعدة بيانات): الأعمال، الباقات، أكواد التتبع، الإعدادات
- `includes/settings.php`: الإعدادات الافتراضية وتوليد أكواد التتبع
- `ads.php`: يولّد `ads.txt` من معرّف AdSense
- `data/projects.json` و `data/settings.json`: البيانات المحفوظة
- `uploads/`: صور المشاريع
- `logo.svg`: الشعار
