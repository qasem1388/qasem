# فيديو موشن جرافيك — قاسم للتطوير الرقمي

فيديو طولي **1080×1920** مدته **30 ثانية** (30fps) مع تعليق صوتي ومؤثرات صوتية وموسيقى.

الملف النهائي: `qasem-promo-30s.mp4`

## السيناريو والتوقيت

| الوقت | المشهد | التعليق الصوتي |
|---|---|---|
| 0–3 ث | **الهوك**: "مشروعك بدون موقع؟" + قفل يسقط بصدمة | مشروعك بدون موقع؟ يعني بابك مقفول! |
| 3–8 ث | ظهور الشعار والهوية + فكرة ← واقع رقمي | في قاسم للتطوير الرقمي، نحوّل فكرتك لواقع رقمي يبيّض الوجه. |
| 8–14 ث | موقع يُبنى أمامك + مؤشر السرعة، ثم متجر وإشعارات طلبات | نصمم لك مواقع احترافية وسريعة، ومتاجر إلكترونية تبيع عنك ليل ونهار. |
| 14–17.6 ث | تطبيق جوال + إشعار + أيقونات تدور حول الجوال | وتطبيقات جوال، تخلّي عملاءك معك وين ما راحوا. |
| 17.6–22 ث | "ليش قاسم؟" ثلاث بطاقات مزايا | تصميم عصري، أداء عالي، ودعم مستمر لين توصل لهدفك. |
| 22–30 ث | **اتخاذ إجراء**: لا تتأخر + زر "اطلب استشارتك المجانية" + الشعار + "الرابط في البايو" | لا تتأخر! تواصل معنا اليوم، وخلّ مشروعك يبدأ صح. قاسم، للتطوير الرقمي. |

الانتقالات: زوم ومسح بالتدرّج وأشرطة ملونة وفلاش وglitch، ولكل انتقال مؤثر صوتي (whoosh / impact / riser / glitch / pop / ding / click).

## إعادة البناء

```bash
python3 tts.py <models_dir> voiceover        # توليد التعليق (Piper ar_JO-kareem عبر sherpa-onnx)
python3 audio.py                              # مؤثرات + موسيقى + ميكس -> build/soundtrack.wav
node render.js build/frames.mp4 30 30         # رسم الإطارات من index.html (Playwright)
ffmpeg -i build/frames.mp4 -i build/soundtrack.wav -c:v copy -c:a aac -b:a 192k -shortest qasem-promo-30s.mp4
```

- لتعديل النصوص/الألوان: `index.html` (دالة `render(t)` تحدد كل حركة حسب الزمن).
- لتعديل التعليق: `voiceover/lines.json` ثم أعد تشغيل `tts.py` و `audio.py`، وحدّث `VO_START` إذا تغيّرت المدد.
