# متغيرات البيئة

انسخ `.env.example` إلى `.env` محليًا، أو أضف القيم في **Secrets** على Replit. لا تضع أي سر داخل الكود أو في Git.

| المتغير | إلزامي | الافتراضي | الوصف |
|---|---|---|---|
| `NODE_ENV` | لا | `development` | `production` في بيئة الإنتاج (يفعّل الكوكيز الآمنة ويُلزم بـ `SESSION_SECRET`) |
| `PORT` | لا | `3000` | منفذ الخادم |
| `HOST` | لا | `0.0.0.0` | عنوان الاستماع |
| `SITE_URL` | موصى به | — | الرابط النهائي للموقع بدون `/` في النهاية. يُستخدم في Canonical و Sitemap و Open Graph |
| `TRUST_PROXY` | لا | `true` | الثقة بترويسات البروكسي (مطلوب خلف Replit/Nginx للحصول على IP و HTTPS الصحيحين) |
| `SESSION_SECRET` | **نعم في الإنتاج** | يُولّد مؤقتًا في التطوير | مفتاح توقيع الجلسات. استخدم 48 حرفًا عشوائيًا على الأقل |
| `SESSION_MAX_AGE_HOURS` | لا | `8` | مدة صلاحية جلسة المدير (تتجدد مع النشاط) |
| `DATABASE_URL` | موصى به للإنتاج | — | رابط PostgreSQL. إن لم يُحدد يُستخدم SQLite |
| `DATABASE_SSL` | لا | `false` | `true` لقواعد البيانات السحابية التي تتطلب SSL |
| `SQLITE_FILE` | لا | `data/database.sqlite` | مسار ملف SQLite |
| `ADMIN_EMAIL` | عند أول تشغيل | `admin@example.com` | بريد المدير الأول (يُنشأ فقط إذا لم يوجد أي مستخدم) |
| `ADMIN_PASSWORD` | موصى به | يُولّد عشوائيًا | كلمة مرور المدير الأول (8 أحرف على الأقل). إن لم تُحدد تُطبع كلمة مرور مولدة في السجل |
| `ADMIN_NAME` | لا | `مدير النظام` | اسم المدير الأول |
| `SEED_DEMO` | لا | `true` | تعبئة بيانات تجريبية عند أول تشغيل (`false` لتعطيلها) |
| `UPLOAD_DIR` | لا | `uploads` | مجلد الملفات العامة |
| `PRIVATE_STORAGE_DIR` | لا | `storage/private` | مجلد الملفات الخاصة (السير الذاتية) |
| `MAX_IMAGE_SIZE_MB` | لا | `5` | الحد الأقصى لحجم الصورة |
| `MAX_PDF_SIZE_MB` | لا | `20` | الحد الأقصى لحجم ملف PDF |
| `BACKUP_DIR` | لا | `backups` | مجلد النسخ الاحتياطية |
| `DEFAULT_LOCALE` | لا | `ar` | لغة الموقع الافتراضية (جاهز لـ `en` مستقبلًا) |
| `TEST_DATABASE_URL` | لا | — | لتشغيل الاختبارات على PostgreSQL (**تُمسح القاعدة بالكامل**) |

## توليد مفتاح الجلسات

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```
