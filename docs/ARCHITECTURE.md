# المعمارية

## الطبقات

```
┌──────────────────────── الواجهة (React + TypeScript) ────────────────────────┐
│ features/*  صفحات وميزات   │ shared/ui  مكونات   │ shared/api  عميل الأوامر   │
└──────────────────────────────────────┬────────────────────────────────────────┘
                                       │ Tauri IPC (invoke) — JSON فقط
┌──────────────────────────────────────▼────────────────────────────────────────┐
│ commands/        محوّلات رفيعة: فك المدخلات + التحقق من الجلسة والصلاحية      │
│ application/     حالات الاستخدام: حدود المعاملات، التدقيق، الجلسات          │
│ domain/          قواعد العمل الصافية: المال، القيد المزدوج، التحقق، الأدوار   │
│ infrastructure/  SQLCipher، المهاجرات، المفاتيح، Argon2، المستودعات          │
└──────────────────────────────────────────────────────────────────────────────┘
```

- الاعتماديات تتجه للداخل فقط: `domain` لا يعرف قاعدة البيانات ولا Tauri، لذلك يُختبر بسهولة.
- الواجهة لا تحتوي أي منطق محاسبي؛ كل قاعدة يُعاد التحقق منها في Rust، والقواعد الحرجة مرة ثالثة في قاعدة البيانات (CHECK/Triggers).

## القرارات المحاسبية

| القاعدة | التطبيق |
|---|---|
| تمثيل عشري دقيق | المبالغ تُخزَّن كأعداد صحيحة بالهللة (`INTEGER`)، وتنتقل كنصوص عشرية `"1150.00"`، ولا يُستخدم `float` إطلاقًا |
| القيد المزدوج | `JournalEntryDraft::validate` ← `BalancedEntry` (لا يمكن الترحيل دون المرور بالتحقق) + Trigger يتحقق من التوازن عند إدراج آخر سطر |
| الترحيل الذري | معاملة `BEGIN IMMEDIATE` واحدة تشمل الرأس والأسطر والتدقيق |
| منع تعديل المرحّل | Triggers تمنع UPDATE/DELETE على القيود والأسطر؛ التصحيح بقيد عكسي فقط |
| منع تكرار الترحيل | فهرس فريد على `(source_type, source_id)` + فحص مسبق |
| الترقيم | تسلسلي دون فجوات داخل المعاملة |
| إقفال الفترات | القيد يجب أن يقع في فترة مفتوحة (Trigger + خدمة)، والفترات لا تتداخل |
| التاريخ | ميلادي ISO-8601 داخليًا؛ الهجري (أم القرى) للعرض فقط |

## إضافة وحدة جديدة

1. مهاجرة SQL جديدة `000N_name.sql` وإضافتها إلى `MIGRATIONS` (لا تُعدَّل المهاجرات المنشورة أبدًا).
2. قواعد العمل في `domain/`، ثم الخدمة في `application/`، ثم الأمر في `commands/` مع صلاحية `Permission`.
3. في الواجهة: دالة في `shared/api/commands.ts`، وصفحة في `features/`، وتغيير `status` في `app/modules.ts` إلى `ready`.
