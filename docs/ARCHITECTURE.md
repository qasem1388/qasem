# البنية المعمارية

## نظرة عامة

```
                ┌──────────────────────────────── المتصفح ────────────────────────────────┐
                │  الموقع العام (HTML من الخادم)           لوحة التحكم /admin (تطبيق JS)   │
                └───────────────┬──────────────────────────────────────┬──────────────────┘
                                │ GET صفحات + POST نماذج               │ JSON API + CSRF
┌───────────────────────────────▼──────────────────────────────────────▼──────────────────┐
│ Express (src/app.js)                                                                     │
│  Helmet/CSP • Compression • Sessions (DB) • loadUser • Static (/uploads, /assets ...)    │
│                                                                                          │
│  routes/public  ── siteContext (إعدادات + قوائم + فوتر + SEO) ── views/*.ejs             │
│  routes/admin   ── auth • meta • dashboard • settings • media • menu • private files     │
│                 └─ resources.js (CRUD عام لكل الأقسام)                                    │
│                                                                                          │
│  core/: resources (تعريف الأقسام) • validate • sanitize • storage • permissions • audit   │
└───────────────┬───────────────────────────────────────────────┬─────────────────────────┘
                │ Knex (استعلامات معاملة)                       │ fs
        ┌───────▼────────┐                             ┌────────▼─────────────────────┐
        │ PostgreSQL /   │                             │ uploads/ (عام)               │
        │ SQLite         │                             │ storage/private/ (سير ذاتية) │
        └────────────────┘                             └──────────────────────────────┘
```

## مبادئ التصميم

1. **مصدر واحد للحقيقة لكل قسم**: `src/core/resources.js` يعرّف كل جدول (الحقول، الأنواع، التحقق، أعمدة القائمة،
   الفلاتر، البحث، الترتيب، الصلاحية، رابط المعاينة). يقرأه الخادم للتحقق والصلاحيات، وتقرأه لوحة التحكم
   (عبر `/api/admin/meta`) لتوليد الجداول والنماذج تلقائيًا. هذا يمنع تكرار الكود ويجعل إضافة قسم جديد سريعة.
2. **فصل الواجهات**: الموقع العام يُولّد من الخادم (أفضل لمحركات البحث وأسرع للزائر)، ولوحة التحكم تطبيق
   صفحة واحدة يتواصل مع API فقط. لا يعتمد أحدهما على الآخر.
3. **الإعدادات كمخطط**: `settings-schema.js` يعرّف مجموعات الإعدادات وقيمها الافتراضية، وتُخزّن في `site_settings`
   (مفتاح/قيمة) مع ذاكرة مؤقتة تُمسح عند كل تعديل.
4. **الأمان في الخادم**: التحقق من المدخلات والصلاحيات وتنقية HTML تتم في الخادم دائمًا؛ واجهة لوحة التحكم مجرد مستهلك.
5. **قابلية التوسع**: خدمة التخزين معزولة (يمكن استبدالها بـ S3)، قاعدة البيانات عبر Knex (PostgreSQL للإنتاج)،
   الجلسات في قاعدة البيانات (تسمح بتشغيل أكثر من نسخة من الخادم).

## تدفق طلب في لوحة التحكم (مثال: تعديل خبر)

1. `PUT /api/admin/r/news/5` مع ترويسة `X-CSRF-Token`.
2. `loadUser` يحمّل المستخدم وصلاحياته من الجلسة → `requireAuthApi` → `verifyCsrf`.
3. `routes/admin/resources.js` يتحقق من صلاحية `media.manage` (صلاحية قسم الأخبار).
4. `validate.prepareInput` يتحقق من كل حقل حسب نوعه وينقّي المحتوى (`sanitizeRich`) ويتحقق من تفرد الـ Slug.
5. الحفظ عبر Knex، ثم تسجيل العملية في `audit_logs`، وإرجاع السجل المحدث.

## تدفق طلب في الموقع العام (مثال: خبر)

1. `GET /media-center/news/:slug` → `siteContext` يحمّل الإعدادات والقوائم والفوتر.
2. يُجلب الخبر؛ إن لم يكن منشورًا يُعرض فقط لمدير مسجل مع `?preview` (وضع المعاينة).
3. تُبنى بيانات SEO (العنوان، الوصف، Open Graph، Canonical، NewsArticle JSON-LD) ويُعرض القالب.

## لوحة التحكم (admin/)

| الملف | الدور |
|---|---|
| `js/app.js` | التهيئة، القائمة الجانبية، التوجيه بين الصفحات (History API) |
| `js/api.js` | عميل API (CSRF، إعادة التوجيه عند انتهاء الجلسة، رفع الملفات مع نسبة التقدم) |
| `js/fields.js` | مكونات الحقول: نص، محرر، صورة، ملف، معرض، مرفقات، لون، أيقونة، علاقة، صلاحيات... |
| `js/views/list.js` | قائمة عامة: بحث، فلاتر، ترتيب، سحب وإفلات، تفعيل، حذف، تصدير |
| `js/views/form.js` | نموذج عام: إضافة/تعديل، نشر، معاينة، تحذير التعديلات غير المحفوظة |
| `js/views/media.js` | مكتبة الملفات ونافذة اختيار الملفات |
| `js/views/menu.js` | منشئ القوائم بالسحب والإفلات |
| `js/views/settings.js` | صفحات الإعدادات مع معاينة الألوان |
