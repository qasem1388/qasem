# قائمة الفحص النهائية قبل الإطلاق

استخدم هذه القائمة قبل تسليم الموقع أو إطلاقه، وبعد أي ترقية كبيرة.
البنود المعلَّمة بـ 🤖 تغطيها الاختبارات الآلية؛ شغّلها أولًا ثم أكمل الفحص اليدوي.

```bash
npm run lint && npm run typecheck   # جودة الكود
npm test                            # اختبارات الوحدات (22 اختبارًا)
npm run build && npm run test:e2e   # اختبارات المتصفح (حاسوب وجوال)
```

> تُشغَّل اختبارات المتصفح على قاعدة بيانات اختبار مزروعة بالبيانات التجريبية، **لا على قاعدة الإنتاج**. تنشئ مديرًا مؤقتًا، وتحذف كل ما أرسلته عند الانتهاء.

---

## 1) الجوال (iPhone وAndroid — عرض 360 إلى 430 بكسل)

- [ ] 🤖 لا يوجد تمرير أفقي في أي صفحة.
- [ ] 🤖 القائمة الجوالية تُفتح وتُغلق وتنتقل للصفحة المختارة.
- [ ] زر الاتصال وزر واتساب العائم يعملان ويفتحان التطبيق الصحيح.
- [ ] النماذج: لوحة المفاتيح المناسبة تظهر للجوال والبريد، والحقول لا تختفي خلفها.
- [ ] رفع ملف من الجوال (كاميرا أو ملفات) في نموذج التوظيف وعرض السعر.
- [ ] معرض الصور: السحب والإغلاق يعملان باللمس.
- [ ] شريط موافقة ملفات تعريف الارتباط لا يغطي أزرارًا مهمة، ويمكن إغلاقه (عند تفعيل التحليلات).
- [ ] النصوص العربية مقروءة دون تداخل، والأرقام والهواتف تظهر باتجاه صحيح.
- [ ] الوضع الأفقي (Landscape) لا يكسر التخطيط.

## 2) سطح المكتب (Chrome وSafari وEdge وFirefox)

- [ ] 🤖 الصفحات الرئيسية تُحمَّل دون أخطاء JavaScript.
- [ ] 🤖 الصفحة غير الموجودة تعرض 404 بلغتها.
- [ ] 🤖 التبديل بين العربية والإنجليزية يحافظ على الصفحة نفسها، ويضبط `dir` و`lang`.
- [ ] القوائم المنسدلة تعمل بالفأرة ولوحة المفاتيح (Tab وEnter وEsc).
- [ ] كل الروابط في الهيدر والتذييل تعمل، ولا روابط لأقسام معطّلة.
- [ ] الصور واضحة على الشاشات عالية الدقة، ولا يوجد تشوه في النسب.
- [ ] الطباعة (Ctrl+P) لصفحة خدمة أو خبر مقروءة.
- [ ] 🤖 لا مشكلات وصول حرجة (axe) في الرئيسية وصفحة التواصل باللغتين.
- [ ] التنقل الكامل بلوحة المفاتيح، مع ظهور مؤشر التركيز ورابط «تخطَّ إلى المحتوى».

## 3) لوحة التحكم `/admin`

- [ ] 🤖 الصفحات المحمية تحوّل إلى تسجيل الدخول.
- [ ] 🤖 كلمة المرور الخاطئة تعرض رسالة عامة لا تكشف وجود الحساب.
- [ ] 🤖 كل صفحات اللوحة الرئيسية تفتح دون أخطاء.
- [ ] 🤖 إضافة محتوى من اللوحة يظهر فورًا في الموقع باللغتين، والحذف يزيله.
- [ ] تعديل الهوية (الشعار، الألوان، الخط) ينعكس على الموقع، وزر «استعادة الافتراضي» يعمل.
- [ ] رفع صورة إلى مكتبة الوسائط واستخدامها في خدمة أو مشروع.
- [ ] محرر النصوص: عناوين، قوائم، روابط، صور، جداول، ومعاينة الصفحة قبل النشر.
- [ ] القوائم: إعادة الترتيب وإخفاء عنصر وإضافة رابط فرعي.
- [ ] تعطيل قسم اختياري (مثل التوظيف) يخفيه من القوائم وخريطة الموقع، وصفحاته تعرض 404.
- [ ] الصلاحيات: **المحرر** لا يصل إلى المستخدمين والإعدادات، و**المشاهد** لا يستطيع التعديل.
- [ ] سجل العمليات يسجل الدخول والتعديلات والتصدير والتنزيل.
- [ ] تغيير كلمة المرور من «حسابي» يُخرج الجلسات الأخرى.
- [ ] تصدير CSV يفتح في Excel بالعربية بشكل صحيح.
- [ ] زر «تحديث صفحات الموقع» يعمل (الإعدادات العامة ← صيانة).

## 4) النماذج والإشعارات

- [ ] 🤖 نموذج التواصل: الأخطاء تظهر بجانب الحقول، والمدخلات تبقى بعد الخطأ، ويعرض رقمًا مرجعيًا `CM-…` عند النجاح.
- [ ] 🤖 عرض السعر: يرفض ملفًا مزيفًا (امتداد PDF ومحتوى غير PDF)، ويقبل PDF حقيقيًا مع رقم `RQ-…`.
- [ ] 🤖 التوظيف: السيرة الذاتية إلزامية، ورقم الطلب `JA-…`.
- [ ] 🤖 تحديد المعدل: الإرسال المتكرر يُرفض برسالة واضحة.
- [ ] 🤖 الطلبات تظهر في صناديق الوارد الثلاثة.
- [ ] رسالة اختبار البريد من «الإشعارات والبريد» تصل، ولا تذهب إلى الرسائل المزعجة (فعّل SPF وDKIM وDMARC).
- [ ] تنبيه الفريق يصل إلى المستلمين المحددين، و«الرد» يذهب مباشرة إلى بريد المرسل.
- [ ] رسالة التأكيد للعميل تصل بلغة النموذج الذي استخدمه (عربي RTL أو إنجليزي LTR).
- [ ] اختيار الخدمة مسبقًا من زر «اطلب الخدمة» في صفحة الخدمة.
- [ ] تنزيل المرفقات والسير الذاتية من اللوحة فقط، والرابط المباشر لا يعمل بعد تسجيل الخروج.

## 5) الأمان

- [ ] 🤖 ترويسات الأمان موجودة: CSP، وX-Frame-Options، وnosniff، وReferrer-Policy، دون X-Powered-By.
- [ ] 🤖 لوحة التحكم غير قابلة للأرشفة ولا للتخزين المؤقت (`noindex` و`no-store`).
- [ ] 🤖 الملفات الخاصة والتصدير تتطلب تسجيل الدخول.
- [ ] 🤖 لا يمكن الخروج من مجلد الرفع (`/uploads/../`).
- [ ] 🤖 ملف الجلسة HttpOnly وSameSite=Lax ومحصور في `/admin`.
- [ ] 🤖 المحتوى المنسق يُعقَّم من السكربتات، وملفات CSV محمية من حقن الصيغ.
- [ ] الموقع يعمل على HTTPS فقط، وHTTP يحوّل تلقائيًا (افحص بـ [SSL Labs](https://www.ssllabs.com/ssltest/)، والهدف A أو A+).
- [ ] ترويسة `Strict-Transport-Security` موجودة في الإنتاج.
- [ ] تسجيل الدخول يُحظر مؤقتًا بعد 5 محاولات خاطئة.
- [ ] لا توجد حسابات افتراضية؛ المدير الأول أُنشئ بالأمر `admin:create`.
- [ ] ملف `.env` غير موجود في Git، وصلاحياته `600`.
- [ ] منفذ PostgreSQL مغلق من الخارج (`sudo ufw status`)، ولا يقبل إلا اتصالات محلية.
- [ ] `TRUSTED_PROXY_HOPS` مضبوط حسب البنية (Nginx وحده = 1، Cloudflare + Nginx = 2).
- [ ] `/.well-known/security.txt` يعرض بريد تواصل صحيحًا.
- [ ] تحديثات الأمان التلقائية مفعّلة على الخادم.

## 6) محركات البحث والأداء

- [ ] 🤖 `sitemap.xml` يتضمن الصفحات باللغتين مع `hreflang`.
- [ ] 🤖 `robots.txt` يمنع `/admin`.
- [ ] 🤖 البيانات المنظمة (Organization وWebSite) موجودة في الرئيسية.
- [ ] «السماح لمحركات البحث بالأرشفة» **مفعّل** في الإنتاج، و**معطّل** في نسخة الاختبار.
- [ ] عنوان ووصف مناسبان لكل صفحة رئيسية باللغتين، وصورة مشاركة 1200×630.
- [ ] اختبار المشاركة: [Facebook Debugger](https://developers.facebook.com/tools/debug/) أو معاينة رابط في واتساب.
- [ ] [Rich Results Test](https://search.google.com/test/rich-results) بلا أخطاء.
- [ ] Lighthouse على الجوال: الأداء 90+، وإمكانية الوصول وأفضل الممارسات وSEO 95+.
- [ ] الصور الحقيقية مضغوطة (JPG أو WebP بعرض لا يتجاوز 2000 بكسل).
- [ ] إن فُعّلت التحليلات: لا تُحمَّل قبل الموافقة (أداة المطور ← Network)، و«إدارة ملفات تعريف الارتباط» في التذييل يعمل.

## 7) المحتوى والبيانات النظامية

- [ ] استُبدل كل المحتوى التجريبي (الخدمات، المشاريع، الأخبار، العملاء، الآراء، الصور).
- [ ] **أُطفئ «وضع العرض التجريبي»** من الإعدادات العامة.
- [ ] رقم السجل التجاري والرقم الضريبي صحيحان ومطابقان للوثائق الرسمية.
- [ ] لا شعارات أو أسماء عملاء دون إذن مكتوب.
- [ ] الصور مرخّصة أو مملوكة للمنشأة.
- [ ] سياسة الخصوصية والشروط وسياسة ملفات تعريف الارتباط راجعها مختص، ومتوافقة مع **نظام حماية البيانات الشخصية (PDPL)**.
- [ ] أرقام الهواتف وواتساب والبريد والعناوين وأوقات العمل صحيحة، والفروع على الخريطة في مواقعها.
- [ ] الوظائف المنتهية مغلقة.
- [ ] النصوص الإنجليزية مراجَعة لغويًا (ليست ترجمة آلية حرفية).

## 8) التشغيل والاستمرارية

- [ ] `https://النطاق/api/health` يعرض `ok`، ومربوط بخدمة مراقبة تنبهك عند التوقف.
- [ ] النسخ الاحتياطي اليومي يعمل، ومعه نسخة خارج الخادم (راجع [BACKUP.md](BACKUP.md)).
- [ ] **جُرّبت استعادة نسخة فعليًا** مرة واحدة على الأقل.
- [ ] ملف `.env` محفوظ في مكان آمن خارج الخادم.
- [ ] تجديد شهادة HTTPS التلقائي يعمل (`sudo certbot renew --dry-run`).
- [ ] حسابات اللوحة: حساب لكل شخص بأقل صلاحية تكفيه، ولا حسابات مشتركة.
- [ ] سُلّمت للعميل بيانات الدخول بطريقة آمنة، مع دليل الاستخدام (README).
